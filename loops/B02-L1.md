# B02-L1 — In-App Weather Status

**Backlog:** B02 (PRD §12) · **Loop:** L1 · **Date:** 2026-07-19
**Previous loop:** none

## Plan (post-grill)

Live weather card on Home. **No migration / no DB** — ephemeral fetch. Escalation
(external API key) resolved: user provided an OpenWeatherMap key, stored in `.env`
(gitignored), used **server-side only** so it never reaches the browser.

- **Source**: OpenWeatherMap current-weather. Key `OPENWEATHER_API_KEY` in `.env`. Verified live: `?lat&lon&appid&units=metric&lang=th` → 200, Thai `weather[0].description`, `main.temp` °C, `weather[0].id` code, `name` city.
- **Server fn** `src/lib/weather.functions.ts` → `getWeather({lat, lon})`: reads `process.env.OPENWEATHER_API_KEY` (throw if missing), `fetch`es OWM, returns `{ temp: Math.round(main.temp), description, code: weather[0].id, city: name }`. Key stays server-side.
- **Location** `src/hooks/use-weather.ts`: `navigator.geolocation.getCurrentPosition` → {lat,lon}; fallback Bangkok (13.75, 100.5) on deny/error/SSR. TanStack Query (`useServerFn` + `useQuery`) keyed on coords, mirroring `use-wardrobe`.
- **Card** `src/components/WeatherCard.tsx` on `src/routes/index.tsx` (Home, near top): emoji (from code group) + temp°C + Thai description + city + deterministic clothing hint from a local map (code group + temp thresholds → Thai hint). `sky` tone per §4.2 weather/context card. No notification permission.
- **Hint map** (deterministic, no AI): thunderstorm/rain → พกร่ม; cold (≤~20°C) → เสื้อกันหนาว; hot clear (≥~32°C) → เสื้อบางเบา/แว่นกันแดด; else → กำลังสบาย.

## Implemented

- `.env` — `OPENWEATHER_API_KEY` appended (gitignored, not committed)
- `src/lib/weather.functions.ts` — `getWeather({lat,lon})` server fn; reads key server-side, fetches OWM, returns `{temp,description,code,city}`
- `src/hooks/use-weather.ts` — geolocation (Bangkok fallback) + `useQuery` keyed on coords
- `src/components/WeatherCard.tsx` — `bg-sky` card; exported pure `weatherHint(code,temp)`; emoji + temp + Thai desc + city + hint; loading placeholder; null-safe
- `src/routes/index.tsx` — `<WeatherCard />` mounted after header, before hero
