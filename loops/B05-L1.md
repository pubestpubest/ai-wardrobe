# B05-L1 — Outfit History Calendar view

**Backlog:** B05 (PRD §12) · **Loop:** L1 · **Date:** 2026-07-19
**Previous loop:** none

## Plan (post-grill)

Monthly calendar of outfits worn per day. Grilled data-model decision: a **new
wear-log** (no worn-date data existed — matches only have a save-date, the
`outfits` table is unused). New user-data table → scoped by RLS from birth
(post-B07 pattern). Calendar mounts as a **view toggle on the Matches page**
(no bottom-nav change). Re-wear prevention deferred (the wear-log enables it later).

- **Migration `014_outfit_wears.sql`**: `outfit_wears(id uuid pk, user_id uuid references auth.users, match_id uuid references matches on delete cascade, worn_date date not null default current_date, created_at timestamptz)`. Enable RLS + `auth.uid() = user_id` (using+with check, pg_policies guard). Index on (user_id, worn_date).
- **`src/lib/outfit-wears.functions.ts`**: `.middleware([requireSupabaseAuth])` + user-scoped `context.supabase`. `logWear({ matchId, wornDate? })` inserts `user_id: context.userId` + match_id + worn_date (default today); `getWears()` returns the user's wears (RLS-scoped); `removeWear({ id })`.
- **`src/hooks/use-outfit-wears.ts`**: session-gated (`enabled: !!session`) + key scoped to `session.user.id`; `wears` query + `logWear`/`removeWear` mutations (invalidate). Mirror use-matches.
- **Wear action**: "ใส่ชุดนี้วันนี้" button on saved match cards (`MatchCard.tsx`) → `logWear(matchId)` → toast + invalidate.
- **Calendar** `src/components/OutfitCalendar.tsx`: month grid (prev/next month nav via local state, no lib — native Date math), each day cell shows the match(es) worn that day (map `wear.match_id` → match name/emoji via `useMatches`, client-side — no server join). Mounted in `src/routes/matches.tsx` behind a toggle (แมตช์ list ↔ ปฏิทิน).

**Deferred (noted):** re-wear prevention; bumping item `wear_count`/`last_worn` when an outfit is worn (kept separate from per-item "ใส่วันนี้").

## Scrutinize findings

_(Opus, fresh. RLS/scoping verified clean (user-scoped, unforgeable user_id, session-gated hook, calendar month-math correct across year/leap boundaries). Verdict: fix-then-ship.)_

- **blocker** — wear date computed in UTC (`toISOString()`) but calendar renders local → UTC+7 users 00:00–06:59 log to yesterday + today-highlight mismatch — **fixed here** (hook computes a local date key, passes as `wornDate`)
- **major** — `match_id on delete cascade` destroyed wear history when a saved match is deleted — **fixed here** (`on delete set null`; UI already falls back to "ชุด" for a missing match)
- nit — RLS `with check` doesn't validate `match_id` ownership (integrity only, no leak — matches RLS blocks reading a foreign match) — **deferred**
- nit — `removeWear` exported but no caller yet (future delete-wear UI) — **deferred**
