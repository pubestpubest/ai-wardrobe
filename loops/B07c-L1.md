# B07c-L1 — Scope matches + body-model, privatize scan bucket

**Backlog:** B07c (PRD §12, under B07) · **Loop:** L1 · **Date:** 2026-07-19
**Previous loop:** B07b-L1 (items scoping — same pattern)

## Plan (post-grill)

Third B07 slice: scope `matches` + `body_models` per-user (B07b pattern) and
**privatize the body-scan bucket** (live exposure: scan photos world-readable +
`getBodyModel` returns the global-latest scan to everyone). Grilled bucket
decision: **private bucket + server-signed URLs**.

- **Migration `013_scope_matches_body.sql`**: add `user_id uuid references auth.users` (nullable) to `matches` + `body_models`; drop each "Guest mode — open" policy, add RLS `auth.uid() = user_id` (using+with check, pg_policies guard); set `body-model-images` bucket `public = false` and drop its "public read" storage policy.
- **`matches.functions.ts`**: getMatches/saveMatch/updateMatch/removeMatch → `.middleware([requireSupabaseAuth])` + user-scoped `context.supabase` (keep the `as any` casts — matches not in generated types); `saveMatch` writes `user_id: context.userId`; RLS gives owner checks (closes id-only update/delete).
- **`body-model.functions.ts`**: `getBodyModel` → user-scoped, fetch the **caller's own** row (`.eq("user_id", context.userId)`, fixes global-latest leak); `generateBodyModel` writes `user_id`. Both return **signed URLs** (`createSignedUrl(path, 3600)` via service-role admin) not public URLs; derive the storage path from the stored value (handle both full public URL and bare path). Uploads stay service-role.
- **`use-matches.ts` + `use-body-model.ts`**: session-gate (`enabled: !!session`) + key scoped to `session.user.id` (mirror use-wardrobe).
- **Claim**: extend the profile claim (`claimOrphanItems` → `claimOrphans`) to also reclaim orphaned `matches` + `body_models` (service-role, `user_id is null → caller`); button label → "อ้างสิทธิ์ข้อมูลเดิม", toast per-table counts.

**Consumers unaffected:** images are plain `<img src>` (`virtual-model.tsx`, `profile.tsx`) → signed URLs drop in. Item scoping (B07b) + the storage bucket for `wardrobe-images` (still public — separate follow-up) untouched.
