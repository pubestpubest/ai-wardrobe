## Scrutinize findings

_(Opus, fresh, security-weighted. Authz boundary verified **fail-closed on every axis**: `assertAdmin` first in every write before any DB call; empty/undefined `ADMIN_EMAILS` or email → deny; case/whitespace safe; client can't forge admin (server re-derives from JWT); `id` not spoofable on create; reads unchanged/public. Verdict: fix-then-ship.)_

- **major (deploy precondition, not a diff defect)** — the gate trusts the JWT `email` claim; with Supabase auto-confirm on + an admin email not pre-registered, someone could self-register that email and pass — **documented** as **ADMIN-1** (§13): require email confirmation + pre-register admin emails before go-live
- nit — `affiliateUrl`/`imageUrl` were any-non-empty-string but render as `<a href>`/`<img src>` for all users (stored-XSS via `javascript:`) — **fixed here** (`httpUrl` = `.url()` + http(s)-scheme refine)
- nit — card `<button>` nested the edit `<button>` (invalid DOM) — **fixed here** (card → `<div role="button" tabIndex onKeyDown>`)
- nit — `amIAdmin` can reject (middleware) not just return false — **left** (client query defaults false + `enabled:!!session` → fails closed)
