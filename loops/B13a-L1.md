## The hazard this loop closes

Ground truth checked live before planning:

```
affiliate_products grants — anon:          DELETE,INSERT,REFERENCES,SELECT,TRIGGER,TRUNCATE,UPDATE
                            authenticated: DELETE,INSERT,REFERENCES,SELECT,TRIGGER,TRUNCATE,UPDATE
policies:                   Public read catalog / SELECT / {public} / using (true)
CHECK constraints:          0
```

Writes are blocked today **only** because no write policy exists. The moment
B13b adds `Owners manage own store items` as a permissive `FOR ALL` policy, those
table-wide grants become live — every column writable by any authenticated user
whose row passes the policy, with no value validation anywhere (zero CHECKs; the
`httpUrl` refinement lives only in B10's admin-path zod).

Revoking first means B13b can add its policy against a table where the only
writable columns are the ones it grants back.

## Plan (post-grill)

1. **`supabase/migrations/023_affiliate_products_harden.sql`**

   ```sql
   revoke insert, update, delete on public.affiliate_products from anon, authenticated;
   ```

   Nothing else — no grant, no policy, no CHECK. Safe today: every reader and
   writer of this table goes through `adminClient()` (service-role), verified in
   B11-L1 and unchanged since. `service_role` is untouched, so B10's admin editor
   and the AI path keep working. Comment must state that B13b adds the policy and
   the narrow grants **together with** the CHECKs, and must never restore the
   table-wide form.

2. **`getMyStoreItems`** in a new `src/lib/store-items.functions.ts` — behind
   `requireSupabaseAuth`. Resolves the caller's store, returns its
   `affiliate_products` rows. Read-only this loop.

3. **`src/hooks/use-store-items.ts`** — TanStack Query wrapper. **Must return
   `isLoading: !session || isLoading` and surface `isError`** — the B12b-L2/L3
   trap: a query disabled by `enabled: !!session` reports `isLoading === false`,
   and a failed fetch is not the same as "no items".

4. **`src/routes/store.items.tsx`** — read-only grid of the store's items (image
   or emoji, name, price, category), an empty state, a loading state and an error
   state. A "เพิ่มไอเท็ม" affordance is **not** in this loop.

5. **`StoreBottomNav`** — enable the ไอเท็ม tab (drop the disabled / "เร็ว ๆ นี้"
   treatment) now that the route exists.

Out of scope: create/edit/delete, the package cap, image upload, the ownership
policy and its column grants (all B13b); B14–B16.
