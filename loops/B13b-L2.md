## Fixed

- **BLOCKING** — cleared optional fields silently didn't save. `toInput` now
  emits `""` instead of `undefined`, **and** `imageUrl`/`affiliateUrl` became
  `httpUrl.or(z.literal(""))`. Both halves were required: `z.string().url()`
  rejects `""`, so fixing only `toInput` would have converted a silent no-op
  into a validation error on the image-remove button. Verified against the real
  schema: `""` accepted for imageUrl/affiliateUrl/description, `javascript:`
  still rejected, and the handler's `p.x || null` turns `""` into a real clear.
- **MAJOR** — the style field now holds raw text in draft state and splits only
  in `toInput`. Previously `a` `,` `b` collapsed to the single tag `ab`.
- **MINOR** — zod mirrors the DB CHECKs (`name` trimmed, `emoji` trimmed + max
  16, `price` finite); verified `1e999`, a 20-char emoji and a whitespace-only
  name now return Thai messages instead of raw constraint text.
- **MINOR** — zod failures surface `issues[0].message` instead of a JSON blob.
- **MINOR** — `AffiliateProductFields` (B10 admin editor) gained the same bounds,
  so `024`'s CHECKs don't regress it into raw English errors.
- **MINOR** — UUID validation on the three id inputs.
- **MINOR** — the `ponytail:` comment now says what actually shipped: the
  app-side check is for the _message_, `025`'s trigger is the _enforcement_.
- **NIT** — the save button disables during delete.

left an undefined `isDeleting`. tsc went 7 → 8 and caught both; back to baseline.
